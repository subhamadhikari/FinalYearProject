# 🧠 Brain Tumor Segmentation Web Application

A full stack application for automated brain tumor segmentation from MRI images using deep learning models.

## 📌 Features
- Upload brain MRI images.
- Perform tumor segmentation using a trained deep learning model.
- Visualize segmented results.
- Simple, intuitive web interface.

## 🛠️ Tech Stack
- **Backend:** FastAPI, Python, Pydantic
- **Deep Learning:** Tensorflow
- **Frontend:** React, TypeScript, Tailwind CSS
- **Others:** MySQL
